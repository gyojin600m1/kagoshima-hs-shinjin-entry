# 第34回 鹿児島県高等学校新人水泳競技大会 エントリー確認（非公式）

2026年8月29日(土) 鴨池公園水泳プール（屋内50m×10レーン）／開会式9:40・競技開始10:00
全種目タイムレース決勝・競技No.1〜34 ＋ 県対抗リレー選手選考レース（No.35 女子／No.36 男子）

選手・保護者が出場種目とだいたいの泳ぐ順番を調べるための、**個人が作った非公式の確認用ページ**です。
公式のスタートリストではありません。

## できること

- **選手検索** … 名前（ひらがなでも可）・学校名で検索
- **種目別** … エントリータイム順の一覧
- **日程** … 競技No.順のプログラム
- **リレー** … 申込チーム一覧
- **組・レーン** … 10レーンでの**予想**（第1組＝最も遅い組、組内は速い順に中央から外へ）

**★突破** は（第88回末弘杯）全九州高校新人の長水路標準記録をエントリータイムが上回っていることを、
**校内◯位** は同じ種目・同じ学校の中でのエントリータイム順を表します。
九州の出場権は「同一校内3位以内」かつ「決勝3位以内 または 標準突破」なので、その2つを並べて見るためのものです。
★は**出場権が確定したという意味ではありません**。
