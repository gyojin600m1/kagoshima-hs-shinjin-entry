## できること

- **選手** … 名前（ひらがなでも可）・学校名で検索
- **種目** … エントリータイム順の一覧
- **日程** … 競技No.順のプログラム。**予定時刻・公式の組数・休憩**まで入っています
- **リレー** … 申込チーム一覧
- **組・レーン** … 8レーンでの**予想**（第1組＝最も遅い組、組内は速い順に 4→5→3→6→2→7→1→8）
- **大会情報** … 入館時間・W-UPのレーン割・招集・リレーオーダーの提出期限・表彰と結果の扱いなど当日の決まりごと

**★突破** は（第88回末弘杯）全九州高校新人の長水路標準記録をエントリータイムが上回っていることを、
**校内◯位** は同じ種目・同じ学校の中でのエントリータイム順を表します。
九州の出場権は「同一校内3位以内」かつ「決勝3位以内 または 標準突破」なので、その2つを並べて見るためのものです。
★は**出場権が確定したという意味ではありません**。
